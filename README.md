# Проект робота Доставщика команды "Хорошие дела"

Основные директории проекта:
- Arduino - код для платы Arduino Mega, разбит на модули в папке model
- OpenMV - код для платы OpenMV H7, основная задача - передача данных на плату Arduino
- Hoverboard - настроенный проект открытого [репозитория](https://github.com/EFeru/hoverboard-firmware-hack-FOC.git) прошивки для гироскутеров
